# 方法与图例

## 这是什么

对 **豆包工作（Doubao Work）** Agent 云沙箱运行时的 **观察型 teardown** 笔记。材料来自产品对话内的现场取证（让模型在沙箱里执行命令、读配置、测网络）。**非**官方文档。

## 图例

| 标记 | 含义 |
|------|------|
| **实测** | 有路径、命令、响应头或挂载证据 |
| **推断** | 由旁证推出，未直接读到配置 |
| **未测到** | 尝试过但仍缺证据 |

## 方法（简述）

1. 在 Doubao Work 对话中要求 Agent 做分层勘察。
2. 只采信其给出的可复核标识（路径、环境变量名、模块名、端口）。
3. 合并进 `docs/` 对应主题文；轮次记入 [`../changelog.md`](../changelog.md)。
4. 不保存密钥、Cookie、完整他人会话正文。

## 局限

- 观测随镜像 / 函数 revision 变化。
- 安全审查、外层网关 token、加密参数等可能在容器外，容器内不可见。
- 模型可能误读或遗漏；重要结论尽量要求「命令 + 路径」。
