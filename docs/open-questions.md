- 热池待命与借出后的补跑逻辑、配置档 `all` / `ci`。  
- 办公版开关主要影响劫持域名清单。  
- 上传接口在不指定路径时，默认落到 `/tmp/<文件名>`。  
- AIO（内部多 CLI 集成代号）/ 创作画布 CLI / 镜像构建号等指纹。
